# Что нужно дополнить

- у каждого доклада отдельный ролик на YouTube;
- у каждого доклада отдельный ролик в VK Видео;
- у каждого доклада ссылка на слайды;
- у каждого митапа фото на странице;
- у каждого митапа ссылка на фотоальбом в ВК или на Яндекс Диске, лучше оба.
