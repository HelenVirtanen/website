# Задача 06, отчёт записан дирижёром

Шапка и меню по макету. Строка с адресом и `t.me` вынесена за `<nav>`, поэтому не прилипает. Крестик стоит на месте бургера, переключение через `data-nav-open`. Меню закрывается по клику только на саму панель, иначе клик по адресу внизу закрывал бы его. Логотип берёт `t('hero.title')`, потому что `site.name` равен `MoscowCSS Meetup`.

Для снимков: `data-visual="navbar"` теперь снимает только прилипшую строку. Неиспользуемые `nav.telegram`, иконки `TG`, `TGSmall` и токены `tgLinkButton*`, `navLogo*` чистятся в задаче 10. Контраст текста с `opacity` 0.4 и 0.6 ниже AA, это требование макета.
