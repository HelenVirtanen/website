# @moscowcss/content — как писать контент

Весь контент сайта лежит здесь обычными файлами `.md`: страницы, митапы, доклады, спикеры, партнёры
и вопросы из блока «ЧАВО». Пишите Markdown: заголовки `##`, списки `-`, ссылки `[текст](https://…)`.
Другие форматы (`.mdx`, `.yml`, `.json`) не используются.

## Раскладка

```
src/
  pages/<язык>/index.md          главная: описание сообщества
  events/<язык>/<номер>.md       митап; номер митапа — имя файла (31.md → 31-й митап)
  talks/<язык>/<имя>.md          доклад
  speakers/<язык>/<имя>.md       спикер
  speakers/assets/<имя>.jpg      фото спикеров, общие для всех языков
  partners/<язык>/<имя>.md       партнёр митапа
  faq/<язык>/<имя>.md            вопрос и ответ из «ЧАВО»
```

- `<язык>` — `ru` или `en`.
- `<имя>` — латиница в нижнем регистре, цифры и дефисы: `daria-egorova`, `gamification-in-business`.
  По имени файла другие файлы ссылаются на этот.
- **Перевод** — тот же путь в папке другого языка: `talks/ru/anchor-and-popover.md` и
  `talks/en/anchor-and-popover.md`. Переводятся тексты: заголовки, описания, подписи. Всё остальное
  одинаково в обоих языках (см. «Что должно совпадать»).

## Поля по коллекциям

Обязательные поля отмечены знаком «да». Если обязательное поле пропущено или записано неверно,
сборка упадёт и назовёт файл и поле.

### `pages` — главная

| Поле | Обязательное | Что |
|---|---|---|
| `title` | да | Заголовок страницы (`<title>`), до 70 символов. |
| `description` | да | Описание для поисковиков и соцсетей, 50–160 символов. |
| `telegramUrl` | да | Ссылка на телеграм-канал, `https://t.me/moscowcss`. |
| текст файла | да | Абзац «о митапе». |

### `events` — митап

| Поле | Обязательное | Что |
|---|---|---|
| `date` | да | День митапа: `2026-07-09` (без времени). |
| `time` | да | Начало по московскому времени: `"18:00"` (в кавычках). Часовой пояс писать не нужно. |
| `tagline` | да | Подпись под заголовком: «31 митап сообщества фронтендеров в Звук». |
| `venue.name` | да | Название площадки. |
| `venue.address` | да | Адрес одной строкой. |
| `venue.mapUrl` | нет | Ссылка на карту. |
| `venue.coordinates` | нет | `latitude`, `longitude`, `zoom` — точка на карте. |
| `modes` | да | Список форматов: оффлайн, онлайн, бесплатно. |
| `passportRequired` | да | `true`, если вход по паспорту. |
| `registrationUrl` | нет | Ссылка на регистрацию. |
| `streamUrl` | нет | Ссылка на трансляцию. Пока её нет, поле не пишут. |
| `recordingUrl` | нет | Ссылка на запись после митапа. |
| `partner` | нет | Имя файла партнёра: `zvuk`. |
| `schedule` | нет | Перерывы и активности без спикера: `time`, `title`, `kind` (`break` или `activity`). |
| `draft` | нет | `true` — черновик. |
| текст файла | нет | Дополнительный текст о митапе: подсказки, как добраться. |

Время в `schedule` — `19:40—20:00` (интервал) или `19:40`. Доклады в `schedule` не пишут: они
собираются в расписание из файлов `talks`.

### `talks` — доклад

| Поле | Обязательное | Что |
|---|---|---|
| `event` | да | Номер митапа **в кавычках**: `"31"`. Без кавычек сборка упадёт. |
| `speakers` | да | Список имён файлов спикеров: `- daria-egorova`. Спикеров может быть несколько. |
| `time` | да | Начало доклада, `19:10` (в кавычках). |
| `title` | да | Название доклада. |
| `slidesUrl` | нет | Ссылка на слайды. |
| `videoUrl` | нет | Ссылка на видео. |
| `draft` | нет | `true` — черновик. |
| текст файла | да | Описание доклада. |

### `speakers` — спикер

| Поле | Обязательное | Что |
|---|---|---|
| `name` | да | Имя и фамилия. |
| `role` | да | Должность и место работы. |
| `photo` | нет | Путь к фото: `../assets/<имя>.jpg`. Файл лежит в `speakers/assets/`. Без фото сайт рисует аватар с инициалами. |
| `photoAlt` | если есть фото | Что на фото — для экранных читалок. |
| `links` | нет | Список ссылок: `label` (подпись) и `url`. |
| `draft` | нет | `true` — черновик. |

### `partners` — партнёр

| Поле | Обязательное | Что |
|---|---|---|
| `name` | да | Название. |
| `handle` | да | Адрес в телеграме, `@ZVUK_JOBS`. |
| `url` | нет | Ссылка на партнёра. |
| `logo` | нет | Логотип: `../assets/<имя>.svg` (или `.png`) в `partners/assets/`. Без него выводится название. |
| `qrUrl` | нет | Адрес для QR-кода под логотипом (`https://…`). QR сайт рисует сам. |
| `tagline` | да | Короткое описание. |
| `features` | да | Карточки: `title`, `description` — обязательные, `footnote` (сноска) — нет. |
| `draft` | нет | `true` — черновик. |

### `faq` — вопрос из «ЧАВО»

| Поле | Обязательное | Что |
|---|---|---|
| `title` | да | Вопрос, заглавными буквами, как на карточке. |
| `order` | да | Порядок карточек: 1 — первая слева. |
| текст файла | да | Ответ в Markdown. |
| `draft` | нет | `true` — черновик. |

В ответе перенос строки пишите обратной косой чертой в конце строки (`\`): без неё две строки
склеятся. Строку, которая начинается с «1.», начинайте с `1\.`, иначе Markdown сделает из неё список.
Звёздочку `*` в тексте пишите как `\*`.

## Ссылки и текст

Все ссылки — только `https://…`: сборка не пропустит `http:`, `javascript:` и `data:`. Текст файла —
только Markdown: HTML-теги (`<div>`, `<img>`, `<script>`) сборка отклоняет. HTML-комментарий `<!-- … -->` — тоже
HTML: пояснения пишите в frontmatter строкой с `#`.

Митап считается идущим ещё 4 часа после начала: пока он идёт, главная показывает его как ближайший.

## Связи

Связь хранится только в докладе: `event: "31"` и `speakers: [daria-egorova]`. Список докладов
митапа и список докладов спикера сайт собирает сам, их не пишут. Имена в связях — это имена файлов
без языка и расширения. Если такого файла нет в том же языке, сборка упадёт и назовёт доклад.

## Что должно совпадать между языками

Эти поля в переводе копируются из русской версии один в один, и сборка проверяет, что они не
разошлись:

- митап: `date`, `time`, `passportRequired`, `venue.mapUrl`, `venue.coordinates`, `registrationUrl`,
  `streamUrl`, `recordingUrl`, `partner`, время и `kind` в `schedule`;
- доклад: `event`, `speakers`, `time`, `slidesUrl`, `videoUrl`;
- спикер: `photo`, `links`;
- партнёр: `url`, `handle`, `logo`, `qrUrl`;
- вопрос FAQ: `order`;
- главная: `telegramUrl`.

Поменяли дату или спикера — поправьте оба языка.

## Черновик

`draft: true` оставляет митап, доклад, спикера, партнёра или вопрос FAQ в репозитории, но прячет с сайта. Схема при этом
всё равно проверяется. Полей нет — значит `draft: false`, опубликовано. Языки публикуются
независимо.

## Правка с телефона

1. Откройте github.com и найдите нужный файл в `packages/content/src/…`.
2. Нажмите карандаш («Edit this file»).
3. Поправьте текст и нажмите **Commit changes**.
4. Дождитесь сборки сайта: если в файле ошибка, в логе будет его путь и название поля.

Перевод правится отдельным файлом по тому же пути в другой папке языка.

## Новые файлы

Заготовки создают команды из корня репозитория:

```bash
pnpm new:event 32                         # номер митапа
pnpm new:talk gamification-in-business
pnpm new:speaker daria-egorova            # без фото: на сайте будет аватар с инициалами
pnpm new:partner zvuk
pnpm new:faq afterparty
```

Команда создаёт файлы сразу в `ru/` и `en/` и ничего не перезаписывает: если хоть один файл уже
есть, она назовёт его и не создаст ничего. Все заготовки появляются с `draft: true`;
заполните значения (подсказки — строки с `#` во frontmatter заготовки, их можно оставить), добавьте фото спикера, если оно есть, и
уберите `draft: true`. Партнёр и вопрос FAQ тоже создаются черновиками; опубликованный митап не может ссылаться на партнёра-черновика.
Шаблоны лежат в `packages/content/templates/`.
