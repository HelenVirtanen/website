title: "CSS как API: токенизация дизайн-системы в 2026"
---

Речь пойдет о том, как CSS перестал быть просто слоем стилизации и превратился в полноценный интерфейс между дизайном, разработкой и продуктом. Разберём, как современные дизайн-токены работают на уровне native CSS: @property, cascade layers, container queries, custom properties, design tokens pipelines и интеграция с Figma/Storybook. Поговорим о том, почему громоздкие UI-kit’ы уступают место гибким token-driven системам, как строить масштабируемую архитектуру темизации для разных платформ и брендов, а также какие ошибки чаще всего ломают консистентность интерфейсов.
