Делать сайты адаптивными можно не только опираясь на viewport, но и на размер родительского контейнера. Эту возможность предоставляет новый подход в верстке - CSS Container. В докладе я подробно расскажу, как пользоваться новыми единицами измерения (cqw, cqh, cqi, cqb, cqmax, cqmin), правилом @container и продемонстрирую, как это упрощает создание адаптивного дизайна.
