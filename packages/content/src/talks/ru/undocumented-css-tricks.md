В современном CSS мы часто ищем обходные пути вокруг трудноуловимых ошибок в браузере. Но трудность заключается в том, чтобы научиться творчески применять данные нам возможности CSS. В своем докладе я расскажу о некоторых недокументированных полезных приемах CSS, позволяющих создавать гибкие и легкие решения для широкого круга задач, которые будут удобны в сопровождении и, насколько это возможно, совместимы с существующими стандартами.
