В наше время даже самый простой сайт подгружает сотни килобайт javascript кода. Мы используем JS, чтобы переходить по ссылкам, собирать бандл, рисовать изображения и для много другого. Но есть задачи, которые требуют простого и быстрого решения. Например создание сайта с несколькими страницами и возможностью перехода между ними. Меня зовут Иван Бабков и я расскажу вам как используя исключительно CSS (и HTML) создать одностраничное приложение.
