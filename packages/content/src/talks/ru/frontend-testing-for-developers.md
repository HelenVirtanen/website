Мало кто из разработчиков любит править баги. Увы, без них не обходится ни один проект, но их количество можно и нужно сводить к минимуму. Я расскажу очевидные вещи о тестировании фронтенда самими разработчиками. И какие инструменты для этого использовать. Коснусь темы здорового перфекционизма в работе. Покажу чек-листы для самопроверки. И раскрою тайну того, как убедить дизайнера в неправоте, показав только один файл в коде.
