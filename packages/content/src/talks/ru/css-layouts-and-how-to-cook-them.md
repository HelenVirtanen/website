Изначально CSS предназначался для оформления документов и приходилось ухищряться для создания более сложных интерфейсов сайтов. Теперь же у нас есть аж два мощных средства для раскладки элементов. Рассмотрим что они могут, как ими пользоваться и какие имеют особенности.
