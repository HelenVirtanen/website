CSS — мощный и выразительный инструмент, позволяющий создавать впечатляющие вещи. Однако начинающему верстальщику принципы работы некоторых свойств могут показаться чернокнижной магией. Я покажу примеры, как можно приручить уже известные свойства и эффективно использовать их. Также мы познакомимся с незаслуженно обделенными вниманием фишками CSS. Эти знания существенно облегчат жизнь начинающему разработчику и помогут в полной мере использовать возможности верстки для решения своих повседневных задач.
