title: "CSS as an API: design system tokenization in 2026"
---

This talk is about how CSS stopped being just a styling layer and became a full interface between design, development and product. We look at how modern design tokens work at the level of native CSS: @property, cascade layers, container queries, custom properties, design token pipelines, and integration with Figma/Storybook. We talk about why bulky UI kits give way to flexible token-driven systems, how to build a scalable theming architecture for different platforms and brands, and which mistakes most often break the consistency of interfaces.
