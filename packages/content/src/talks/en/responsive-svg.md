In modern interfaces elements become graphically complex: non-trivial shapes, fills and animations appear. All of this has to be taken into account when developing for mobile and desktop devices. Approaches to responsive layout have existed for a long time, but they are not always applicable to SVG. Using the layout of a button with an arrow as an example, I will show how to make an SVG responsive.
