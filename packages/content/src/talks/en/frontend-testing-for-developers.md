Few developers enjoy fixing bugs. Alas, no project is free of them, but their number can and should be kept to a minimum. I will cover the obvious things about developers testing the frontend themselves, and which tools to use for it. I will touch on healthy perfectionism at work, show self-check checklists, and reveal how to convince a designer they are wrong by showing just one file in the code.
