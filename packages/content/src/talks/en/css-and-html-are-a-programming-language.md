Everyone says you need CSS in JS and HTML in JS. In fact you should do exactly the opposite ☺ HTML and CSS are a powerful programming language that lets us do very cool things. In this talk you will learn about the Turing machine and Turing completeness. You will understand what applications can be written using only HTML and CSS.
