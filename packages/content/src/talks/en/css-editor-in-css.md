Let us try to build a component for CSS demos. One where you can edit CSS and the styles are applied on screen immediately without affecting elements outside the demo. And where you can resize the code editor. And with dark theme support too, because that is fashionable now. And to make the task interesting, we will forbid ourselves from using JavaScript. Ready?
