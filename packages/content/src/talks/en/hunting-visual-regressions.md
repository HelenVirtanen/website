What can be wrong with markup? Anything at all! Markup is not as simple as it seems: it can fail to match the design or the code style, and it can work crookedly in different browsers. It can also break in unexpected places. Breaking markup is easy, testing it is hard. Meanwhile, a single CSS rule can break a page. Why can markup we have not touched break, and what should we do about it?
