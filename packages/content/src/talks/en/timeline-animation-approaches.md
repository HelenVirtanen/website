We all run into animation tasks for elements and whole sections one way or another.
It is easy when it is basic hover behavior or loops. It is different when the result depends on a number of parameters, on time, on the progress of several elements, and all of it changes dynamically.
We will go through animation options and implementing timelines with GSAP. We will look at its pros and cons, as well as alternatives. Most importantly, we will understand which animations CSS is enough for and when it is time to reach for a library.
