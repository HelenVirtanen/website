title: "The power of pseudo-selectors in modern CSS"
---

Using pseudo-elements and pseudo-classes as examples, I will show how modern CSS is used in web development. Many people know them and use them at work, but CSS keeps moving and pleasing us with new features. We will go through the current support using Baseline and Can I use, and what can already be used in production.
