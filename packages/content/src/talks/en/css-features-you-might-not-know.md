CSS is a powerful and expressive tool that lets you build impressive things. Yet a beginner may find the way some properties work a bit like black magic. I will show how to tame properties you already know and use them effectively. We will also look at underappreciated CSS tricks. This knowledge makes a beginner's life much easier and helps make full use of markup for everyday tasks.
