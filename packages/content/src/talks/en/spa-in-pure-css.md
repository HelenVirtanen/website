Nowadays even the simplest site loads hundreds of kilobytes of JavaScript. We use JS to follow links, build bundles, draw images and much more. But some tasks call for a simple and fast solution, for example a site with several pages and the ability to move between them. My name is Ivan Babkov, and I will show you how to create a single-page application using nothing but CSS (and HTML).
