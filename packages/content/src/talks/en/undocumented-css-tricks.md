In modern CSS we often look for workarounds around elusive browser bugs. The real difficulty is learning to apply the capabilities CSS gives us creatively. In my talk I will cover some undocumented, useful CSS tricks that allow flexible, lightweight solutions to a wide range of tasks, easy to maintain and, as far as possible, compatible with existing standards.
