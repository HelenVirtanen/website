title: "Browser tools guarding performance"
---

In the talk we will discuss methods of analyzing and optimizing web application performance with the developer tools in the Chrome browser. First we will talk about what Lighthouse can do and its limitations. Then we will move on to the more advanced DevTools features, such as the "Memory" and "Performance" tabs. We will explain the difference, what they are useful for and which problems they help find.
