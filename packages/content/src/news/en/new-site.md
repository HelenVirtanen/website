We have published the new css.moscow. The old site was a single announcement page; now it is the whole community archive.

- **Meetups since 2017**: the programme, venue, photos and recordings of every one.
- **Talks and speakers**: every talk and speaker has a page, and the lists have search and filters by year and recordings.
- **Search** across the whole site.
- **Reviews** from speakers, guests and organizers.
- **News**: you are reading the first page of this section.
- Russian and English versions, light and dark themes, and an RSS feed of meetup announcements.

The site puts the next meetup on the home page by itself and rebuilds every night, so a finished meetup never stays there as upcoming.

The site is open: the code is on GitHub and the content is plain Markdown files. Found a mistake or want to add photos, a recording or slides? Send a pull request or write to the organizers.
